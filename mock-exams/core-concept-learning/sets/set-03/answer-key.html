Q1 · Find the queue that actually grows

Select 1.

A museum consortium answers conservators' status questions in two minutes; applications wait nine days for inconsistent condition descriptions to be normalized. Scheduling rules are reliable. One intervention must reduce days until schedulable without changing scheduling authority. Which scope BEST fits?

  1. Incorrect. Automate status notifications, treating fewer inquiries as the first milestone toward faster application processing.

    Inquiry volume is a different outcome; fewer questions do not establish that applications become schedulable any sooner.

  2. Correct. Normalize descriptions into reviewed intake fields, feeding the existing scheduling process under its approved priorities.

    This addresses the observed prerequisite blocking scheduling while leaving reliable rules and the existing decision authority in place.

  3. Incorrect. Launch a status assistant to reduce interruptions, then improve descriptions through its conversations in a later phase.

    Status assistance may reduce inquiries, but postpones the constraint responsible for the nine-day wait measured by this sponsor.

  4. Incorrect. Replace scheduling rules with a planning agent that infers priorities directly from the unstructured condition descriptions.

    This combines normalization with an unnecessary decision change, increasing scope without evidence that existing scheduling rules cause delay.

The measurement concerns readiness for scheduling, so the architecture must address the input dependency that holds applications upstream. A useful language task can sit inside a stable deterministic process. Scope selection should follow observed delay and retained authority rather than the requested interface.

An instrument portal asynchronously generates expensive calibration narratives over several minutes.
