Q1 · Find the queue that actually grows

Select 1.

A museum consortium wants an assistant to answer conservators' status questions. Observation shows that status answers take two minutes, while applications wait nine days because condition descriptions arrive in inconsistent language and must be normalized before scheduling. Scheduling rules are already reliable. The sponsor funds one intervention and will measure days until an application becomes schedulable. Which scope BEST targets that outcome without changing the scheduling authority?

  1. Automate status notifications and report reduced inquiry volume as the first milestone toward shortening application processing time.
  2. Normalize condition descriptions into reviewed fields at intake, then feed those fields into the existing scheduling process, preserving approved scheduling priorities.
  3. Deploy a status assistant first and use its conversations to improve condition descriptions during a later project phase, to reduce staff interruptions.
  4. Replace the scheduling rules with a planning agent that can infer priorities directly from the unstructured condition descriptions.

  5. Have Claude reproduce transport calculations and compare only the final number against the service during weekly quality reviews.
