Q1 · Move the calculation boundary before the pilot

Select 1.

A tunnel assistant would narrate survey notes and issue clearance, immediately releasing equipment without review. Clearance follows a deterministic formula on calibrated readings; narratives are reviewable. The prototype matches 99 historical verdicts. Which architectural recommendation BEST fits this release boundary?

  1. Correct. Keep clearance in validated code; evaluate source-linked narratives separately under the existing human review process.

    The release requires exact reproducible computation without review; strong historical agreement does not justify moving that boundary into generation.

  2. Incorrect. Teach the formula through worked examples, restricting the generated clearance output to the two permitted labels.

    Examples and constrained labels improve presentation but still leave the critical calculation to probabilistic generation rather than validated code.

  3. Incorrect. Use the historical prototype as a release filter, escalating only notes unlike the 99 observed examples.

    Similarity to observed notes cannot establish the correctness of a new safety-relevant numeric calculation or its unreviewed release.

  4. Incorrect. Keep generated verdicts but require independently worded prompts to agree before automatically releasing equipment.

    Agreement can repeat a shared computational mistake and does not establish the formula execution guarantee required at the release boundary.

The fit decision concerns the consequence and mechanism, rather than a favorable aggregate score. Preserve exact clearance computation in code and use language generation for the reviewable explanation. The historical test remains useful evidence for that narrower assistant, not authorization to replace the release calculation.

Q11 · Measure the residual review burden

  2. Incorrect. 4,800 analyst minutes monthly, down 80%: count review time only for cases escalated to specialists.

Q63 · Make the incident repair reviewable before execution

Select 1.
