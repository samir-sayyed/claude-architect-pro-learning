Q1 · Place the language boundary

Select 1.

A seed laboratory receives narrative field observations and numerical germination counts. Scientists already use a validated formula to calculate the certified germination percentage. They want faster preparation of explanatory notes, but the certificate calculation must remain reproducible. A pilot can identify relevant observations with source links.   2. Have Claude compute percentages and explanations together, then compare only the prose against the scientists’ existing notes.
  3. Build an autonomous research agent that chooses formulas from the observation text and submits completed laboratory certificates.
  4. Use the existing numerical formula to generate every explanation through templates before evaluating the narrative extraction pilot.
