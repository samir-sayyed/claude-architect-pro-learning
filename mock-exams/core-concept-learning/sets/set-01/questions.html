Q1 · Instrument the actual bottleneck

Select 1.

A fictional animation studio wants Claude to shorten delivery of subtitle packages. Editors spend little time translating but wait days for licensors to approve terminology. The proposed business case assumes translation is the delay. No one has measured time in each state, and the licensor approval process cannot change this quarter. Which next step best establishes whether an AI intervention can meet the delivery goal?

  1. Benchmark translation accuracy on finished episodes and approve development if the model exceeds the existing editorial quality threshold.
  2. Prototype automatic terminology approval and demonstrate its possible impact before revisiting the licensor agreement with the business sponsor.
  3. Measure elapsed time by workflow state and compare the addressable translation interval with the required delivery improvement.
  4. Calculate subtitle tokens per episode and use the estimated inference cost to prioritize the smallest affordable translation model.

Q2 · Separate prediction from explanation

Select 2.

A fictional district-heating operator already has a validated tabular forecast of hourly heat demand. Dispatchers struggle to understand forecast changes and ask for a Claude replacement. The engineering owner stipulates that the numeric forecast must remain under the existing validation regime; the real unmet need is explaining changes using weather notes and maintenance reports. Select TWO recommendations that meet that need without expanding the prediction scope.

  1. Train dispatchers to treat explanations as provisional forecasts and select the value they believe best reflects current weather conditions.
  2. Let Claude correct forecast values whenever maintenance notes appear newer than the last structured input used by the predictor.
  3. Evaluate explanation faithfulness and dispatcher comprehension separately from the forecast model’s existing numeric prediction acceptance tests.
  4. Keep the validated forecast as the numeric authority and let Claude explain its supplied drivers using linked operational evidence.
  5. Replace the predictor with Claude and preserve the validation regime by comparing average forecast totals over one historical month.
