ITEM 01 · S06Q24 · DOMAIN 3 · OBJECTIVES 3.5

The correct clause at the wrong time

A lease assistant uses structure-aware chunks that preserve headings, tables, and document relationships. Retrieval finds the correct clause number but sometimes uses a renewal amendment when answering questions about an earlier accounting period. Chunks retain effective-date intervals and lease identifiers, and both versions must remain searchable for historical questions. Which indexing and retrieval change BEST targets the remaining defect without deleting valid history?

Correct: B · select 1

Good chunk boundaries do not settle which version applies. Match temporal and entity constraints explicitly while preserving valid historical evidence.

  1. A · Distractor

    Delete superseded clauses from the index so only the latest renewal terms can be retrieved for either current or historical accounting questions.

    Deleting valid historical evidence violates the requirement to answer earlier-period questions.

  2. B · Correct

    Filter or select evidence by the requested lease and effective interval, preserving supersession relationships and citing the version applicable to that period.

    The missing constraint is temporal applicability, not chunk structure; both historical and current versions remain useful.

  3. C · Distractor

    Increase chunk overlap around each already-complete clause and table, retaining the existing version-agnostic candidate selection and answer generation behavior.

    More local context does not choose the effective version for the requested period.

  4. D · Distractor

    Merge every version of the clause into one generated summary and cite the latest amendment regardless of the accounting period requested.

    A merged latest-version summary can silently apply current terms to a historical question.

ITEM 02 · S06Q03 · DOMAIN 1 · OBJECTIVES 1.3

When a bounded agent is justified

A research team investigates novel material failures. Each observation determines which laboratory records or literature to inspect next, and the number of branches is unpredictable. A fixed workflow now contains hundreds of brittle branches and repeatedly stops on new evidence patterns. The team permits read-only exploration, requires cited findings, and imposes a strict work budget. Which architecture BEST fits these conditions while preserving accountable termination?

Correct: B · select 1

Variable input alone does not justify autonomy, but demonstrated unpredictable evidence-dependent exploration can; retain bounded authority, evidence, and termination contracts.

  1. A · Distractor

    Use a read-only investigative agent with cited findings and a separate budget for each new branch, permitting unlimited branch creation until findings converge.

    Per-branch limits do not enforce the strict total work budget when the number of branches is unpredictable.

  2. B · Correct

    Use a bounded investigative agent with approved read tools, explicit evidence contracts, budget and stopping rules, and escalation when uncertainty remains.

    Adaptive branching is genuinely needed; bounded tools and stopping rules preserve the stated scope and resource limits.

  3. C · Distractor

    Prefetch a fixed evidence packet for one augmented-model call, escalating every unanticipated record need to researchers rather than allowing further read-only exploration.

    A fixed packet turns the recurring unpredictable evidence needs into avoidable manual interruptions instead of supporting bounded exploration.

  4. D · Distractor

    Maintain explicit workflow branches with model-selected parameters, adding each newly observed evidence pattern to the documented branch catalog before automated continuation.

    It keeps the demonstrated brittle enumeration requirement even though evidence-dependent branch structure is unpredictable.
