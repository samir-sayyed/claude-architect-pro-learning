A reusable Skill is still an input boundary

Which THREE design requirements should be verified before enabling this Skill for routine analysis?

Correct: A, C, E · select 3

Procedural reuse does not make executable content or external data trusted; validate inputs and bound execution for every relevant use.

  1. A · Correct

    Limit runtime capabilities to approved analysis needs and evaluate malicious files alongside ordinary spreadsheet workflows before deployment.

    Reusable procedures still need bounded capabilities and testing.

  2. B · Distractor

    Approve the Skill because its instruction file forbids unsafe commands, leaving scripts responsible for interpreting user-provided data as needed.

    Instructions do not repair unsafe argument handling.

    Executable resources belong to the reviewed artifact.

  4. D · Distractor

    Move the script into a commonly cached prompt block so repeated use benefits from the same validation performed during the first request.

    Caching does not validate changed untrusted input.

  5. E · Correct

    Validate script arguments and constrain permitted output locations, treating spreadsheet cells as untrusted data rather than shell command fragments.

    This enforces the concrete execution trust boundary.

A capacity commitment with a rework ceiling

A publishing team handles 24,000 abstracts monthly. Sixty percent will use an assistant, saving four editor minutes per assisted case before rework. Each assisted case needing correction adds six minutes, and recurring evaluation consumes 80 editor hours monthly. The sponsor requires at least 600 net editor-hours released. What maximum assisted-case correction rate supports that commitment, rounded to one decimal percent without overstating the ceiling?

InputValue
Monthly abstracts24,000
Assisted adoption60%
Saving before correction4 min/assisted case
Additional correction6 min/corrected case
Recurring evaluation80 h/month
Required net capacity600 h/month

Correct: C · select 1

Assisted baseline saving is 960 hours; correction consumes 1,440r hours and evaluation consumes 80. Solve the actual capacity commitment before promising it.

  1. A · Distractor

    The correction rate must not exceed approximately 6.7% of assisted cases once additional corrections and recurring evaluation count against the capacity target.

    This unnecessarily leaves more than 180 released hours above the target; it is not the maximum supported correction rate.

  2. B · Distractor

    The correction rate must not exceed approximately 25.0% of assisted cases, treating the maintenance workload as separate from editor capacity.

    This omits the recurring eighty-hour capacity cost.

  3. C · Correct

    The correction rate must not exceed approximately 19.4% of assisted cases, after accounting for adoption and recurring evaluation workload.

    960−1440r−80≥600 gives r≤19.444%.

  4. D · Distractor

    The correction rate must not exceed approximately 63.8% of assisted cases, applying the four-minute saving to every monthly abstract.

    This assumes universal adoption rather than sixty percent.

ITEM 63 · S05Q54 · DOMAIN 6 · OBJECTIVES 6.4

Handoff that preserves the reasoning

A platform team will hand a multilingual RAG assistant to regional support. The package includes infrastructure diagrams and deployment scripts, but regional engineers cannot determine which index revision is paired with each prompt or why a language falls back to human service. The originating team disbands next month. Which TWO additions most directly make the system maintainable after handoff?

Correct: C, D · select 2

Handoff must preserve both what is deployed and why its operational boundaries exist. Receiving-team execution demonstrates transfer better than delivery of documents alone.

  1. A · Distractor

    Supply trend dashboards and a complete infrastructure inventory, asking regional teams to infer language-routing rationale from observed traffic after acceptance.

    Operational metrics and inventory do not explain intended routing or reproduce the evaluated release.

  2. B · Distractor

    Provide a searchable decision-history archive and schedule a one-day knowledge-transfer workshop, letting regional engineers reconstruct configuration relationships during incidents.

    A workshop and archive help, but do not supply the missing authoritative release/configuration mapping.

  3. C · Correct

    Provide a versioned configuration manifest connecting prompts, models, indexes, routing thresholds and the evaluated release artifact.

    Maintainers need a reproducible configuration rather than disconnected files.

  4. D · Correct

    Document routing rationale, escalation ownership and a tested incident/rollback exercise that the regional receiving team performs before acceptance.

    This transfers operational understanding and demonstrates readiness.

  5. E · Distractor

    Transfer all source repositories and developer contact details, treating successful access checks as evidence that regional maintainers can operate the system.

    Code access is useful but does not demonstrate operational understanding or preserve the decision rationale.
